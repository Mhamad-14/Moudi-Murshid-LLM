# Core Murshid notebook

[murshid.ipynb](murshid.ipynb) is the cumulative four-day project notebook. It contains the synthetic service directory, deterministic `FakeClient`, structured ticket handling, read-only synthetic status checks, guardrails, a ten-case golden test suite, caching, metrics, and final report generation.

Use a Python 3.9+ CPU environment and run the notebook from its first cell to the last. The core uses the Python standard library and makes no external model API calls. The generated JSON artifacts are archived in [results/core](../results/core/).

The four optional homework notebooks are stored separately in [homework](../homework/).
